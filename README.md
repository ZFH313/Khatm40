# ختم چهل‌روزه (PWA)

نسخه‌ی وب نصب‌پذیر. بعد از قرار گرفتن روی یک آدرس HTTPS، روی اندروید و آیفون مثل اپ به صفحه‌ی اصلی اضافه می‌شود و بدون اینترنت هم باز می‌شود.

این پروژه روی سیستم من اجرا نشده است. کد بررسی نحوی شده و فایل تقویم تست شده، اما نصب روی گوشی را خودتان امتحان کنید.

## گذاشتن روی GitHub Pages
1. در github.com وارد حساب‌تان شوید.
2. بالای صفحه روی «+» و بعد «New repository» بزنید. یک اسم بدهید (مثلاً `khatm40`)، گزینه‌ی **Public** را انتخاب کنید و «Create repository» را بزنید. حالت Private در حساب رایگان برای Pages کار نمی‌کند.
3. در صفحه‌ی مخزن روی «uploading an existing file» بزنید.
4. فایل‌های داخل پوشه‌ی `khatm40-pwa` را بکشید و رها کنید: `index.html`، `manifest.webmanifest`، `sw.js` و پوشه‌ی `icons`. خود پوشه‌ی `khatm40-pwa` را آپلود نکنید، فقط محتویاتش را.
5. پایین صفحه «Commit changes» را بزنید.
6. به `Settings > Pages` بروید. در بخش Source گزینه‌ی «Deploy from a branch» را انتخاب کنید، شاخه‌ی `main` و پوشه‌ی `/ (root)` را بگذارید و Save بزنید.
7. یکی دو دقیقه صبر کنید و صفحه را تازه کنید. آدرس بالای صفحه شبیه این است: `https://اسم-کاربری.github.io/khatm40/`

## نصب روی گوشی
- اندروید (Chrome): آدرس را باز کنید، منوی سه‌نقطه، بعد «Install app» یا «Add to Home screen».
- آیفون (Safari): دکمه‌ی Share، بعد «Add to Home Screen».

## یادآوری
صفحه‌ی وب نمی‌تواند خودش اعلان زمان‌دار بفرستد. دکمه‌ی «افزودن یادآوری روزانه به تقویم» یک فایل تقویم می‌سازد (رویداد روزانه با هشدار، به تعداد روزهای ختم). فایل را باز کنید تا در تقویم گوشی اضافه شود. اگر ساعت را عوض کنید، فایل جدید بسازید و رویداد قبلی را از تقویم پاک کنید.

## تغییر دادن بعداً
هر وقت فایلی را عوض کردید، دوباره در GitHub آپلود کنید (Add file > Upload files). صفحه چند دقیقه بعد به‌روز می‌شود. اگر گوشی هنوز نسخه‌ی قدیمی را نشان داد، اپ را کامل ببندید و دوباره باز کنید.

## محدودیت‌ها
- تیک‌ها فقط روی همان گوشی و مرورگر ذخیره می‌شوند و پاک کردن اطلاعات مرورگر آن‌ها را پاک می‌کند.
- فونت‌ها از خود گوشی گرفته می‌شوند.
